\# CMS - Manual de Instalación y Uso



\## 1. Introducción



CMS es un proyecto web orientado a servicios audiovisuales, marketing digital y desarrollo web. La página presenta los servicios, trabajos realizados y diferentes formas de contacto.



El proyecto utiliza HTML, CSS y JavaScript, principalmente dentro del archivo `index.html`.



\## 2. Requisitos



Para utilizar o modificar el proyecto se necesita:



\- Windows, macOS o Linux.

\- Un navegador web actualizado.

\- Git para trabajar con el repositorio.

\- Un editor de código como Visual Studio Code.
